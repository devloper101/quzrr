Overview

Built for aggressive, packet-based combat and utility play

Quzr Addon is a Meteor Client addon centered around fast mace-based PvP, teleport-assisted movement, creative utility tools, and automation routines. The project includes a large group of modules for combat, movement, mining, chat automation, and creative item generation.

Mace / Spear Combat

Includes TP-to-target smashes, totem-break sequences, break-through attack patterns, and hit-triggered variants.

Movement Tools

Features instant TP, rise/speed variations, anti-pop movement control, and freecam teleport tools.

Automation

Includes ore tracking, shulker farming, auto totem handling, mass TPA actions, and creeper interruption.

Features

Highlights from the Quzr Addon module set

Mace Combat

  • TpMace — teleport and smash
  • MaceAttect — hit-triggered smash logic
  • UltraAura — target-selection aura
  • Blacklist — mass target list attacks
  • ArrowKiller — projectile redirect / teleports
  • InfiniteReach — long-range attack / break reach

Movement

  • PlayerTp — nearest-player teleport
  • Rise / Speed / AutoRise — vertical packet movement
  • AntiPop — neutralize landing state
  • FreecamTp — teleport from freecam

Automation

  • OreTracker — mine and path toward nearby ores
  • AutoShulkerBox — shulker loop farm helper
  • AutoTotemToHotbar — manage totems automatically
  • AntiCreeper — destroy creepers before detonation
  • MassTpa — spam TPA requests
  • Hitback — auto strike attackers

Chat / Info

  • auto-gg — kill message helper
  • auto-msg — automatic spam / message tools
  • NearestPlayerHUD — nearest-player info
  • Creative item / potion spawners

Requirements

What the addon expects

  • Minecraft 1.21.11
  • Fabric Loader 0.18.6
  • Meteor Client 0.18.6
  • Java 21
  • Use on permissive or test servers only

Important warning

Many modules use packet-based movement or combat logic that can be highly visible to anticheat systems and may lead to kicks or bans on stricter servers.
